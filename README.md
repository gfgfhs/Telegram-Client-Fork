# Telegram Multi-Account Client

Клиент для работы с большим количеством Telegram-аккаунтов (100+) на ПК.

## Возможности

- Управление сотнями аккаунтов через `.session` файлы
- **Регистрация новых аккаунтов** (ввод номера → код → создание)
- Вход в существующие аккаунты + 2FA
- **Авто-поиск бесплатных SOCKS5 прокси**
- Простой CLI

## Важно про бесплатные прокси

Бесплатные прокси:
- Часто мёртвые или очень медленные
- Telegram их часто банит
- Для массовой регистрации почти не подходят

Это лучше, чем ничего, но **платные прокси (residential/mobile) работают в разы надёжнее**.

## Установка

```bash
git clone https://github.com/gfgfhs/Telegram-Client-Fork.git
cd Telegram-Client-Fork
pip install -r requirements.txt
```

## Настройка

1. Открой `config.py`
2. Вставь `API_ID` и `API_HASH` (https://my.telegram.org)
3. `USE_FREE_PROXY = True` — искать бесплатные прокси автоматически

## Запуск

```bash
python main.py
```

### Меню

1. Зарегистрировать / войти по номеру
2. Войти в существующую сессию
3. Список аккаунтов
4. Проверить аккаунт
5. Найти бесплатный прокси заново
6. Выход

## Про интерфейс как в оригинальном Telegram

Полноценный GUI как у Telegram Desktop — это огромный проект (C++ / Qt, десятки тысяч файлов).

Сейчас сделан удобный CLI. Если очень нужен «настоящий» вид:
- Можно запускать несколько копий **официального Telegram Desktop** с разными папками (`-workdir`)
- Или позже сделать простой GUI на customtkinter / PyQt

Напиши, если хочешь простой GUI-менеджер аккаунтов.
