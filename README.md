# Telegram Multi-Account Client

Два инструмента в одном репозитории:

1. **GUI менеджер профилей** (`gui_manager.py`) — быстрая смена аккаунтов с **оригинальным интерфейсом** Telegram Desktop
2. **CLI регистратор** (`main.py`) — регистрация новых номеров + Telethon-сессии

---

## 1. GUI — быстрая смена tdata (рекомендуется)

Каждый профиль = отдельная папка. Telegram Desktop запускается с `-workdir`, поэтому интерфейс **полностью оригинальный**.

### Запуск

```bash
pip install -r requirements.txt   # если ещё не ставил
python gui_manager.py
```

### Как пользоваться

1. Укажи путь к `Telegram.exe` (кнопка «Обзор...»)
2. Нажми **«+ Новый профиль»** → придумай имя
3. Выбери профиль → **«Запустить»** (или двойной клик)
4. В открывшемся Telegram войди / зарегистрируй аккаунт
5. Повтори для следующих номеров

Все данные аккаунта лежат в `tg_profiles/ИмяПрофиля/`.

Можно держать 50–100+ профилей — ограничение только местом на диске.

---

## 2. CLI — регистрация через Telethon

Если нужно массово создавать аккаунты скриптом:

```bash
# config.py → вставь API_ID и API_HASH с my.telegram.org
python main.py
```

Есть авто-поиск бесплатных SOCKS5 прокси (ненадёжные, но бесплатные).

---

## Структура

```
Telegram-Client-Fork/
├── gui_manager.py      ← GUI смены профилей (оригинальный UI)
├── main.py             ← CLI регистрация
├── account_manager.py
├── proxy_manager.py
├── config.py
├── tg_profiles/        ← здесь лежат все профили Telegram Desktop
└── sessions/           ← .session файлы Telethon
```

---

## Важно

- Бесплатные прокси почти всегда плохие для регистрации.
- Массовая регистрация может привести к банам — используй на свой риск.
- GUI-менеджер не требует API_ID — работает через официальный клиент.
